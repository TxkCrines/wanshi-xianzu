# 万世仙族 · 玄天纪 Alpha 0.3

基于上一轮山河新卷继续升级的静态 Web 游戏。

## 本轮变化

姓氏流程修复：新建家族先进入“择姓立族”，支持常用姓氏、自定义输入和复姓。已有存档的确认窗口仍可编辑姓氏；初始族人预览增加“重新选择姓氏”。

山门改为场景沙盘：建筑标记、族长浮动信息、物品式操作栏、族闻、轻量雾气和灵光。各界面使用一致的青铜边框与宣纸窗口。

所有实际弹窗都暂停时间、锁定背景、等待处理，不再计时自动消失。普通进境、未关注族人的日常变化写入族闻；重要通知与抉择进入窗口。重大待决需要同意、拒绝或明确暂缓；通知逐条确认。事件可延后一年保留原抉择，晋阶条件变动可明确暂缓。离线推进遇到未决事件或现有弹窗也中止，并保留未消费的离线余额。

坊市有12种物品：丹药、疗伤露、悟性残卷、法器、药材、灵材、玄灵莲与远行补给。库存每年刷新。物品实际入库、使用或装备；法器可卸下和交换，远行期间锁定装备。材料回售有明确单价，不存在买入即卖出的获利漏洞。

六境：炼气、筑基、金丹、元婴、化神、炼虚。新增境界有小境界修炼、真实突破概率、资源消耗、寿元、失败恢复与丹药加成。家族和建筑扩展到六阶。

元婴后可耗5000灵石、200灵材开辟玄天界。新地图有瑶池药圃、霜天灵矿、太初道宫、归墟裂隙；分别需要元婴、化神或炼虚修士，完成远行获得实际资源和炼丹珍材。玄天炼丹台可炼化神丹和炼虚丹。

族谱默认按代纵向浏览，无需横向拖动。支持姓名搜索、定位、亲缘跳转；全图提供缩放、适应屏幕、空白拖拽、父母及道侣连线。

保留原有婚育、外交、云州远征和六项传承研习；传承界面重绘为物品图标的研习面板。

配乐改为三个独立的原创合成主题，约107至142秒，包含拨弦、笛音、钟音、和声与混响。音色为程序合成，非真人录音。

## 本机运行

```powershell
./Start-Game.ps1
```

默认 http://127.0.0.1:4174/ 。如已有预览服务器，可直接访问它，无需重复启动。

本包无运行依赖，适用于静态托管。GitHub Pages 从分支根目录部署时，上传发布包根目录；从Actions部署时，可运行 `npm run build` 后发布 dist。

## 存档

保存键保持不变。存档版本升至1.3.0；支持原1.2.2以及原核心支持的更旧存档迁移，并保留家族、人物、经营和已学传承。旧版本不能保证读取新增高阶内容。

更新同一网址后点击继续游戏，即可迁移。不同端口或网站之间的浏览器存档独立，需要导出和导入。测试使用独立端口与后期验证档，没有修改玩家正在试玩的存档。

正式网址：https://txkcrines.github.io/wanshi-xianzu/ 。部署状态以原仓库 GitHub Actions 和 Pages 部署记录为准。

## 验证与源码

```sh
npm test
npm run check
npm run build
```

原经营检查13项、新增检查23项，共36项。浏览器验证涵盖真实弹窗停时、交易与物品使用、族谱、地图解锁、后期突破以及桌面和手机视口。

新增文件：frontier.js（高阶、物品与地图）、mature-ui.js（新版界面）、game-ui.css、art/v3/、audio/v3/。core.js 本轮进行了境界、验证、通知与离线逻辑的必要扩展。

美术提示词见art/v3/ART_PROMPTS.md；配乐源码见scripts/compose-score.py。测试专用后期档不在发布包中；高级内容需要在正式游戏中达到条件后解锁。

本交付仍为原生静态Web，不是Cocos工程。它是Alpha 0.3版本，不表示已完成商业级游戏的长期平衡、真人音乐制作或设备兼容性全覆盖。
