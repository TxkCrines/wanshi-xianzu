# 玄天纪原创合成配乐

三个独立的五声音阶主题，由 scripts/compose-score.py 离线生成，未使用外部录音、采样或歌曲。

- bgm_home.wav：128秒，山门主题，拨弦、笛类音色、和声与钟音。
- bgm_world.wav：约142秒，两界山河主题，采用不同旋律、和声行进与点缀钟音。
- bgm_explore.wav：约107秒，远行主题，更快节奏与低频拨弦。

包含开场、主题、变化与回归段落，立体声声像、短反射和混响、首尾淡入淡出。格式为22.05kHz、16bit、立体声WAV；按游戏场景切换，沿用原音量和音频启用逻辑。

这是程序合成音色与配乐，不是真人演奏录音。脚本仅开发时需要 Python + NumPy，游玩无需安装它们。
